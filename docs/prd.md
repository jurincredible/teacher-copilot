# PRD

## Funktsionaalsed nõuded

- [ ] F1: Õpetaja näeb päeva tunniplaani kalendrivaates, kus tunnid on kronoloogilises järjekorras.
- [ ] F2: Õpetaja saab kalendrivaates valida ühe tunni ja liikuda selle klassi-tunni vaatesse.
- [ ] F3: Kui praegu on ajakavas tunni aeg, kuvab süsteem õpetajale kinnituse küsimusega "Kas praegu on see tund?"
- [ ] F4: Õpetaja näeb klassivaates klasse, kellele ta tunde annab.
- [ ] F5: Õpetaja saab klassi avada ja näha selle klassi jooksva õppeaasta tundide loendit.
- [ ] F6: Klassi tundide loend on vaikimisi keritud viimasele juba toimunud tunnile.
- [ ] F7: Kui praegu on tunni aeg, näeb õpetaja tunni vaates nuppu "Salvesta", millega saab alustada hääle salvestamist.
- [ ] F8: Õpetaja saab tunni vaates muuta üherealist "Teema" välja.
- [ ] F9: Õpetaja saab tunni vaates muuta suurt "Kokkuvõte" tekstivälja.
- [ ] F10: Süsteem kuvab tunni vaates "Konspekt" PDF-i, mis on seotud tunni salvestuse või demoandmetega.
- [ ] F11: Õpetaja saab tunni vaates muuta üherealist "Kodutöö" välja.
- [ ] F12: Õpetaja saab tunnile lisada manuse töölehe, dokumendi või PDF-ina.
- [ ] F13: Õpetaja näeb tunni vaates õpilaste nimekirja.
- [ ] F14: Õpetaja saab iga õpilase juures kiire kontrolliga märkida puudumise või hilinemise.

## Mittefunktsionaalsed nõuded

- [ ] N1: Liides on õpetajale arusaadavas eesti keeles.
- [ ] N2: Õpetaja töövoog töötab demo jaoks nii töölaua vaates kui ka telefonis alates 360px laiusest.
- [ ] N3: Esmane töövoog on kasutatav ilma juhendamiseta: õpetaja leiab tunni, avab tunni vaate ja näeb peamisi tegevusi.
- [ ] N4: Tunni vaade rõhutab praktilisi tegevusi: salvestamine, teema, kokkuvõte, konspekt, kodutöö, manus ja kohalolek.
- [ ] N5: AI või demoandmete põhjal loodud sisu on esitatud muudetava mustandina, mitte lõpliku otsusena.
- [ ] N6: Õpilaste nimed ja kohaloleku info ei satu jagatavasse õppematerjali ega PDF-i ilma teadliku vajaduseta.

## Valmis märkimise reegel

Nõue märgitakse `[x]` alles siis, kui see on ehitatud, kontrollitud ja vajadusel seotud failidega märgistatud.
